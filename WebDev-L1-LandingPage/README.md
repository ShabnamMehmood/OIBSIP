# LULU — Flowers & Fragrance

LULU is a visually polished and responsive landing page created for a fictional flowers and fragrance brand.

## Features

- Sticky navigation bar
- Hero section with call-to-action
- Flowers and fragrance collection
- Product showcase
- About LULU section
- Contact section
- Social media section
- Responsive mobile layout
- Hover effects and animations
- Consistent floral-inspired colour palette

## Technologies Used

- HTML5
- CSS3
- CSS Flexbox
- CSS Grid

## Responsive Design

The website is designed to work smoothly on desktop, tablet, and mobile screen sizes.

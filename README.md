# Sabnam — Personal Portfolio

## About the Project

This is a responsive personal portfolio website created to showcase my
background, technical skills, projects, and contact information.

The website has been designed with a clean and minimal professional style.

## Technologies Used

- HTML5
- CSS3

## Features

- Responsive navigation bar
- Hero/Profile section
- About Me section
- Skills section
- Projects section
- Contact section
- GitHub and LinkedIn placeholders
- Smooth scrolling navigation
- Responsive design for mobile devices
- Hover effects and simple animations
